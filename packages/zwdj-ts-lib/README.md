# zwdj-ts-lib

紫微斗数典籍原文库：《紫微斗数全书》卷一至卷三，共 89 篇，原文照录，按书懒加载，简繁等价检索。仅适用于 Node（读包内 `data/` 文件）。

| 书目 ID | 卷 | 收录 | 字形 |
| --- | --- | --- | --- |
| `qs1` | 卷一赋文 | 二十篇成 56 条：骨髓赋、太微赋总括、赋性论、形性赋、女命赋、十等论、得地合格诀、失陷破格诀等一文一条；诸星问答论逐星拆成 37 条 | 繁 |
| `qs2` | 卷二 | 13 条：安身命例与安星诀；诸星入命宫星情与男命、女命、入限吉凶诀；其余十一宫诸星断语 | 简 |
| `qs3` | 卷三 | 20 条：谈星要论、论大限十年祸福、论二限太岁吉凶、定小儿生时诀等 | 简 |

## 用法

```ts
import { getBooks, getEntries, getEntry, getDocsManifest, getDocMarkdown, searchEntries, foldText } from 'zwdj-ts-lib';

getBooks();                                   // 书目（题名、作者、朝代、版本、字形）
getEntries('qs1');                            // 某卷篇目（序号、篇名、大类、字数、来源地址）
await getEntry('qs1', '02');                  // 骨髓赋全文
getDocsManifest();                            // 全库篇目目录，path = `<书目ID>/<篇序号>`
await getDocMarkdown('qs2/13');               // 一篇的 Markdown（标题 + 出处行 + 正文）
await searchEntries('命无正曜', { book: 'qs1' }); // 关键词 AND，简繁等价，篇名命中在前
```

检索不是语义排序：空格分隔的关键词须全部出现，篇名或大类命中的排在正文命中前面。正文保持底本字形，简繁只在比对时折叠（`foldText`），所以简体关键词能查到繁体的卷一，反之亦然。

## 数据来源

`data/` 由 `scripts/gen-data.mjs` 从来源仓库 react-zwds 的 `docs/kb/*.md` 整理，书目配置在 `scripts/books.mjs`。来源仓库是私有的，生成只在维护者本机做；`data/` 随包提交，构建与发布不需要来源仓库。`getCatalog().origin` 记录所据的来源提交。

来源目录里的 `23-续道藏本紫微斗数-十八飞星.md` 有意不收：它是十八飞星体系，星曜与安星法都和《全书》十四主星不同，放进检索容易被当作同一体系引用。维基文库的《全书》只到卷三，卷四（命例）未收。
