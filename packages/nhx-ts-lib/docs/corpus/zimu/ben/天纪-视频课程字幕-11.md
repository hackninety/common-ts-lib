# 天纪-视频课程字幕-11

## 第十一章 六神占断与续卦

### 六神占断论

六神占断法从汉朝以后大量使用，可用在堪舆学（看来龙）、相学（看脸相、动作、纹路、手相）、测字等，凡占断皆逃不出六神。过去相师将此法藏于腹中不讲，直接用以占断。

六神为：青龙、朱雀、勾陈、腾蛇、白虎、玄武。脸上的分布：上方额头发际为朱雀（南方），下方为玄武（北方），左为青龙（东方），右为白虎（西方），东南角与西北角为腾蛇，左上角与右上角为勾陈。八宫属性为木火土金水，腾蛇在巽（木）与乾（金）位。

六神以行看，以神断——不要把字当字，把字当山形来龙的形状就是风水，放到脸上就是相。测字要看神不看行，否则英文全是腾蛇。

#### 青龙

蚕头燕额是青龙。山势下来完整，上面多出小三支角，支角整齐如龙须龙鳞，即真青龙；大到山川河流一个捺出去很有力无断落，也是青龙。六神中以青龙最吉，主大吉。

青龙笔动喜还生，谋用营求事事通，人口增添财禄厚，主人日下尽亨通。

测字举例：有人问婚姻，抽到"孤"字，孤的最后一捺即青龙；孤拆开是瓜与子，得瓜有子，反主有婚有子。

#### 朱雀

尖短交加朱雀行。交叉形为朱雀。测字如"又"字交叉即朱雀，主口舌是非、官讼、家人不安。考期问科举，文字少一点，考试无望且恐有官司纠纷、无妄之灾。房子盖成交叉形也是朱雀。朱雀专指官司、是非、口舌多。

#### 勾陈

弯弓斜月勾陈像。勾陈主事情停滞不前、小事不断。一年换十二个工作，做做停停，变化多但停于原地，无大灾而小祸不断。字形上一点、直下来、尾部上勾都是勾陈。山龙一节一节断掉是勾陈，脸上的纹断断续续也是勾陈。

勾陈逢者事交加，谋事中间件件差，田宅官司多挠括，是非门内有喧哗。

#### 腾蛇

腾蛇长曲势如行。扭弯曲折如乙、乞、风等字。腾蛇主虚惊、家宅不宁、忧虑不堪、不祥之兆。房子盖成S型即腾蛇。山龙扭扭曲曲是腾蛇。相书上的"三曲鼻"侧面看三曲即腾蛇，鹰钩鼻是勾陈，直曲鼻工作到老，正面弯的还害人。腾蛇纹入口主饿死（喉癌、胃癌也算）。

腾蛇遇者主虚惊，家宅逢之尽不宁，出入官谋宜慎取，免教仆马有灾形。

#### 白虎

尾尖口阔为白虎。白虎主戴孝（六亲之丧）、牢狱之灾、病灾、口舌、家财损。风水上来龙反背出去、口阔开不藏风纳气即白虎。字形如"几"、"儿"、"鼠"都是口阔。相上嘴巴大下巴尖的人易犯牢狱，是非口舌多。

白虎逢之灾孝来，出门凡事不和谐，便防失脱家财损，是疾忧人家事乖。

#### 玄武

体态方尖玄武行。幺、丝、姣丝边、广口、方口都是玄武。玄武主失脱、家宅流离、暴贼、失财、小人介入。山龙下来出去又回来、不圆润有尖角死角即玄武。坟墓后有小山头蹲下看不见、站起才露出，主后代出窃贼——此为偷窥之象。

玄武动时主失脱，家宅流离慎方话，更防阴小有灾危，又至小人生拮括。

#### 六神综合应用

一个字可能含多神。如"风"字：第一画为青龙，绞丝为勾陈，三角行为玄武——占老公去向，主证件掉了在外回不来（玄武招口舌，勾陈停滞），但结果还是会回来（青龙）。

看动作、走路、讲话同样适用。走路直行虎步为青龙；突然闪躲为勾陈；讲话从丹田出来刚劲为青龙，言辞闪烁听不清为腾蛇（想骗人），尾音往上走为玄武（小偷）。动作断断续续、有声无音也是勾陈。

宋美龄出国时，对面一人正面看她突然跳开闪躲，此动作即勾陈。烟盒折成一团丢掉为一团乱丝腾蛇。睡觉时外面有人敲门，旁边狗一直叫——两口一狗是哭，卜夫妻主死，卜父母（独子）主父母双全（两口健全）。

灵机占断要中虚——把己变成空杯子才能灵机。第一念最准，卦卜不对再卜第二个就不准了。

#### 风水龙虎与六神

来龙青龙白虎下来，白虎位置突然高一点出去，按六神断。来龙山龙两边有很多交叉角出去、枝节清楚，主富贵人大权。龙的位置结穴发，虎的位置像腾蛇，凶。

金城局：三面山川秀丽围成圆形，朝向好。整个局论整体，论一件事则靠六神协助占卜（写字、灵机等）。

### 天罡二十八宿与罗经

天机道讲天上28天罡星宿。东南西北四个方向各有七宿，四七二十八宿。罗经要拿起来从下面看（南北定出后看罗书角度即各星位置），不要从上面看（会反着）。天上28星宿部列及日月五星关系都在罗经里。

### 斗数扩展与阴宅来龙取向

斗数可扩展：命宫→父母宫→兄弟宫→夫妻宫→子女宫→再往前推祖父祖母、曾祖父曾祖母；子女往后推孙子、曾孙。祖父祖母八字若已无，可从孙推断。三方四正可知祖父祖母。

阴宅上用过世者方向（辰戌丑未），12地支配木火土金水五行。对冲一定相克：龙（辰）与狗（戌）、马（午）与鼠（子）相克。克者也会在一起——克才爱，越克越爱。阴宅立向若与死者相克则不好。

阴宅以易经推时，朝为母为内（入穴为母），坐为父为外，内卦外卦并在一起对照即知何卦。祖父葬在戍宫，命里戍正好为祖父宫，戍龙与命相和；寅卯属木，命中寅配寅龙，属性相同为比肩，相生比肩最好，相克主凶。曾祖父祖母承受的风水来龙最好与命相生或比肩。来龙取向一定要阳生阳、阴生阴，不可阳配阴。

### 斗君起法

斗君从月、时起。一宫代表一年，12宫配12个月。例如5月午时：从子开始数到5月在午宫，再从午时数到午时落在寅宫，斗君即落在寅宫。

定斗君后看今年是何年（如戌年即狗年），从斗君起子，数到戌即为一月，一月一号在隔壁宫，1月13号回到原位，1月26号从1数到26落宫。12循环一次。这是月历算法。

### 卦象续讲

#### 火风鼎

![火风鼎](../img/火风鼎.jpg)

泽火革之后是火风鼎。革物最大者不过鼎——鼎下火、上水，水火本不容，鼎在中间使其相容。鼎之真意是让不相和的能相和，如同法官办案使甲乙和解。

天道：离为明，巽为风为顺，耳聪目明之象。要做中间调解人，必耳聪目明，否则甲乙各有道理回去还吵。

人间道：鼎之相为中实（与坎中实不同——坎中实主险，鼎中实主有才）。行为端正如鼎，此为至善正道，终身不过。今人德薄位尊、知小谋大、力少任重，君王用非其人即招败亡。鼎道公正无私——背私为公，私心私欲放背后，用人要有功勋能让手下信服。

占卜：
1. 云中月现——拨云见月，时节清明中秋。
2. 雀南飞——冬至来临，北人执政；卜国运亦主北人执政。
3. 一子裹席帽——无知之人，不可用。
4. 一人持刀立中——武官、护卫将军、执刑之人。
5. 贵人坐屋内——君王、法官、老板，至公无私。
6. 一鼠——子年、阴谋、属鼠之人。

阳宅火风鼎：二女居长女位，成格。

1. 必嫁贵夫。
2. 果决刚断，婚比姐早，冬至冬天结婚。
3. 当官官运亨通；从商不利。
4. 十一生象皆好，唯肖鼠凶。
5. 科甲大吉——二女儿考大学住东南，若大女儿结婚只剩二女儿则她变长女，让她住中孚卦位更好。

#### 震为雷

![震为雷](../img/震为雷.jpg)

鼎之后是震为雷。主器莫若长子，故鼎之后为长子——重雷，两雷相叠。长子继位则国内外皆震动。

天道：震为雷讲大震动时如何处之。

人间道：人皆"惧而后失"——损失之前必先惧，唯宗庙祭祀时至诚则不畏。君子畏天威（重雷为天威），不畏人威，随时静修自身、夕惕若厉省思己过。处震之道：事发生时先想自己有无错。今人不知雷震之威，只知争功诿过，从不惧己之才不足，终招咎。

占卜：
1. 人在岩上立——危象、摇摇欲坠、特立独行。
2. 一束花开——有果但短暂、少部分人。
3. 文书至——消息、公文到。
4. 一人推车——转变之象；空车无人则无方向。
5. 车上有文字——得官令。
6. 钱财散地——忧心、丧事。父病重卜此卦，准备办丧事，正数三，3天内。

阳宅震为雷：长子居长子位，成格。

1. 承继祖业。
2. 科甲兴旺，金榜题名。
3. 当官官运亨通，但儿子结婚后应住西北（乾为天）。
4. 从商大利，但要正名为负责人——儿子未结婚住东宫才可把家业过给儿子；若住西厢（归妹卦）则可能被同性恋男友骗走。
5. 婚姻平安顺畅，正科红鸾星——命里28岁即28岁结婚。

测字举例：问官司结果，写"重"字——千里发放，发配千里之外。

#### 艮为山

![艮为山](../img/艮为山.jpg)

震为雷的续卦。物动终止——再怎么动终会止。艮为重山，安重坚实之象，上止下静。山天大畜、风天小畜的止是力止，艮为止是安止。

人间道：人之不止因为有欲。佛家讲"眼不见则易止"——看不到就不生欲望。易经提出"无我则止"——不要把自己想得太重要。圣人能使天下顺治，非用法则规范，而是使民安居乐业无欲才是圣人之道。君子知安于其位，不出其职不逾矩；小人不知止，进则唯欲，招咎。能知止者是世界上最快乐的人。

占卜：
1. 五人立——等候、停滞。
2. 东北——陈姓、侯姓。
3. 官吏执镜——清明至大官人。
4. 测字"竞"同音——竞争、三人受牵连遭诉讼。

阳宅艮为山：三子居三子位，成格。

1. 科甲兴旺，读书好。
2. 身体健康平安。
3. 婚姻顺利。
4. 公职大利，进退有据。

#### 风山渐

![风山渐](../img/风山渐.jpg)

艮卦之后是渐卦。止后必有进，渐进之。渐卦讲屈伸消息之理，何时进、如何处。渐进之道——木在山上，山托住木往上长。山可能是才能、贵人，随时补充才能树才稳。读书越多眼光越好鼻子越正；天柱纹靠翻书。

天下之事进必以渐。天下至渐之事唯"女归"——女孩子进入夫家时自然懂渐。其他人到公司就要升官要钱，不懂渐进。

各得正位而后进——在位置上立功后再升，进而有功。一个国家所有人都这样晋升上来，可以正邦国。

占卜：
1. 家人望归——等候而望。
2. 药炉在地——平安无灾。
3. 官人登梯——升官、衣锦还乡；树砍断放地上叫木，官人在木上即"官在木上"。
4. 一枝花落地——落第，金榜不提名；花开不久，生意不长久。

阳宅风山渐：长女居三子位，成格。

1. 科甲不行——大女儿不喜欢念书，查是否住渐卦。
2. 工作心念不定——一天到晚换工作。
3. 身体健康。
4. 婚事难成——无婚。
5. 公职利——官人登梯。

#### 雷泽归妹

![雷泽归妹](../img/雷泽归妹.jpg)

渐必有进，进之后必归。归妹讲女归之道。泽是少女，雷是长男，男动女悦，以悦而动。易经主张以明而动（火雷丰），以悦而动则招凶。

人间道：六五爻讲君王之位——柔居尊位，女处尊位之道要"尚礼不尚饰"。可尊重的女孩子尚礼不尚饰。

占卜：
1. 官人骑虎指云——浮云蔽日，日指君王、父、夫、子；乘乱而进。
2. 小路子在后——随从、生意人。
3. 外杆上有文字——卜疾厄旦夕而亡；揭竿而起要正名（反清复明 vs 推翻清朝建立民国）。
4. 人落次中——去之不得，如鲠在喉。
5. 一人拔须——恃宠之人来相救。

阳宅雷泽归妹：长男居少女位（大儿子住西厢），成格。

1. 男同性恋。
2. 委屈求禄。
3. 无婚。
4. 诸事不顺、短命（艾滋病）。
5. 西厢记——谈恋爱没结果。

### 八字排列与天干地支数

八字排列按子平法，年月日时四柱，各有干支，共八字。批法不按子平法，按元会运世，可用皇极经世或铁板神数批。批时根据天纪64个图读图批注。

起数：天干与地支换算成阿拉伯数字起用数。易经最难懂的是象与数。

天干数：甲六、乙二、丙八、丁七、戊一、己九、庚三、辛四、壬六。

地支数：亥子一六，寅卯三八，申酉四九，辰戌丑未五十。

单数相加为阳数，双数相加为阴数。

### 卦象续讲（续）

#### 雷火丰

![雷火丰](../img/雷火丰.png)

归妹卦后物归必成大，故雷火丰为归妹续卦。丰即丰盛盛大。治丰之道四字：外动内明——动作内明才做。雷是外卦（动），火是内卦（明）。

人间道：以明而动才致丰。反应快要对，否则没用。要内明必须熟读体会易经（诸经之首）。不了解时不要做决策就是最好决策。致丰之道即外动内明。

不明而动的例子：不懂医学听西医怎么做就做什么；中医书没念通就开业，三十年经验累积都是不对的。山天大畜卦，积对的才会看病。

占卜：
1. 龙蛇交错——辰巳之年，正邪相争（龙正蛇邪）。
2. 竹筒喷烟——中空之象，合伙对方空口；竹有坚节，卜婚姻主至死不渝坚决；眉毛淡看不到也主中空。
3. 官人着衣——公家单位丈夫，先破后成。
4. 盒子在地——求财先成后破。
5. 人坐虎上吹笙——闲情逸致、喜事临门，险在下（当官老板手下有虎咬人）。
6. 旱沼泽——池中无水，心力交瘁，财禄快光，破财。
7. 珠落盘——人事先聚后散，合伙先成后破，破后朋友成仇人。

阳宅雷火丰：长子居二女位，成格。

1. 婚事先成后破。
2. 科甲高中——命有科甲星则金榜题名。
3. 个性坚心，感情困扰多，感情上其人逆境难出。
4. 未结婚从商破财，当官老师吉。

#### 火山旅

![火山旅](../img/火山旅.png)

丰卦之后是火山旅。丰到极限必失所安，故旅为续。旅指变换中间的这段时间。

天道：外卦离为火（动而不居），内卦艮为山（止而不动），万民内止之象。天道讲违去不处。

人间道：止之道——知进退。处旅之道：以柔顺而谦下。对上柔顺则上顺利，对手下谦下则下至诚，无咎且顺。今人过刚且自高，不顺易伤；失下人之信则自取倒霉。

占卜：
1. 三星——三台贵人（古司马、司空，今行政院、司法院），相位之人。
2. 贵人台上垂钓——君主相求、老板相求。卜去公司上班大利，重用。
3. 能人出野——离郊入朝封侯。
4. 慕权势而变节——君主不明还要去做即变志节。
5. 一猴一羊——肖猴肖羊，或侯姓杨姓；时间未年申年应之，在野之人突然升部长。
6. 大溪——脱险，命好（小人也会命好）。

阳宅火山旅：二女居三子位，成格。现代人想生一男一女，生一女后想再生儿子，结果连生几女，易得火山旅；或大姐结婚后三姐跑到二女儿位置。

1. 科甲兴旺。
2. 女生男态——不穿裙子喜欢裤子、刺猬头、不戴耳环、讲话声大。
3. 婚事不成——要到猴年羊年方成。
4. 城府深——手纹一条条很深（非直的，握拳设计人的纹）；对付城府深的人方法是不理他，心坚直行，自己滚蛋。

#### 巽为风

![巽为风](../img/巽为风.png)

巽为顺、为入，风无孔不入。旅卦以巽道柔顺行旅，无所不入。

天道：真正的柔顺是阳刚中正之顺——一阴上面两阳压着，要顺阳刚中正的顺到底才是真巽。现在人顺的是权势财力，顺外不顺内，是假巽。

人间道：上下皆顺，百姓顺国家政策，政策顺天命顺时而为。君子重巽之道——申复命令，好政策每天重复，让小人知道君子定义。田获三品有功——上位、本身、下位都分到，分均人为仁；空降部长压过有功之人即分不均不仁。

占卜：
1. 贵人试衣——先破后成（做衣服先剪破布再成衣）。
2. 一人跪受——贵受；占疾病凶（寿衣），流年值卦逢戴孝。
3. 云中燕传书——意外喜讯。问前需把问题确立清楚——问父身体主穿寿衣，问婚姻主喜讯。
4. 人在虎下坐——身处险而不知。
5. 一人射虎中箭——贵人相救。虎走即脱险，时间寅年。

阳宅巽为风：长女居长女位，成格。

1. 科甲旺——射箭即发，发在寸地之上。
2. 逢凶化吉——有贵人射虎。
3. 婚姻大利。
4. 性情稳健处忧不惧——大姐有大姐样。
5. 健康平安。

#### 兑为泽

![兑为泽](../img/兑为泽.jpg)

巽为入，入而后悦，兑为泽讲悦之道。物相入则相悦。

人间道：悦以物——珍惜眼前之物不论好坏。物莫不悦——周围事物跟着相悦，此君子之恒。今人非正道求悦，欲望无限。善巫之人唇不蔽齿、舌舔唇口、讲话没事这样笑——一票小人讲谣言讲得很乐，非以正道求悦，则邪陷。两泽相悦互利，君子观重兑知朋友讲习要互相曾丽（互丽不是互利），互相长进。今人相聚贬损他人、制造谣言，造谣为亡之道，国家社会危亡。

占卜：
1. 悦在天边——秀才登梯。
2. 人坐看一担——师道，老师扛扁担把学生送上天，助人为乐、有人相助。
3. 月在下——清明之治，妈妈在侧无父（后天卦45岁后主父不在）。
4. 秀才登梯——金榜登科。
5. 女在河边立——女人介入先成后破。
6. 文字在上——待机而发（弓射箭即发）。

阳宅兑为泽：三女居本位，成格。

1. 求婚不成，感情复杂——恋爱史可写成小说。
2. 订婚后婚事前先生出事，婚延三年。
3. 科甲顺畅。
4. 公职顺，求财不利。
5. 体健无灾，母在侧无父象。

六个女儿对应爻：1对4，2对5，3对6。老六住西厢也是兑为泽。

#### 风水涣

![风水涣](../img/风水涣.png)

涣为散。忧则聚，悦则散。风水涣——风在水上，风吹水纹跟着动，扩散之象。讲治散之道、处散之道。

人间道：人之离散（夫妻、国家、百姓）都由心——人心离则散。看到打包袱走路是结果，人心在走路之前已散。治散之道要本护中——中庸之道能收合人心，散可聚。圣人观民心最聚时在宗庙，立宗庙收人心。立宗庙立错则主凶。

占卜：
1. 山上有寺——出家状、两军对峙、寸土寸金、土头人作对。
2. 寺尾对尾——旁人作对。
3. 僧人——化外之人、光头人、曾姓。
4. 一人随后——逃避求助化外、世外人。
5. 一鬼在后——内心有鬼处事不明。羊眼猪眼人大恶大凶——眼膨出，眼白黄浊红多，像醉眼，闪开不理。
6. 金甲人在后——正义之师，得民心。

### 先后天卦批注

#### 坤为地

![坤为地](../img/坤为地.jpg)

神天卦批注（如37岁牛年逢坤为地）：

1. 女命忌口舌——十一口在卦中，三口讲话已成虎，何况十一口。
2. 诬陷他人不成。
3. 逢马相克——属马或马年，破财，因己不守。
4. 公职：司法官主贵（军人、警察、法官、外交官四种武官）；一般公职贪污，犯官府、挪用公款、防窃、破财。

坤为地可代表一年、一月、一日，前后连贯互动。要看当年属何年（今年狗年、明年猪年），还要注意夫妻生肖。

#### 水雷屯

![水雷屯](../img/水雷屯.jpg)

先天卦水雷屯：
1. 肖狗者——父母双全，独子。
2. 肖牛者——早年多灾多血光灾，开刀病痛多。
3. 个性胆大过人，麻烦多是非官司总不停。
4. 卦象外险内动（反解为外动内险）。遇险不能止，一止增险。

后天卦水雷屯：
1. 官运亨通，发在文书职（文官、教员）。
2. 位高无权——当参谋顾问，平安。
3. 大器晚成。
4. 挣名夺利必招凶。
5. 酉年需防父母凶——图上犬头回字，狗之前为酉。
6. 浪子无家——家是宝盖头子在内，先天卦后父母过世即浪子无家，耗尽家财一人飘荡。

流年卦水雷屯（牛年）：
1. 事态不明，阻力大。
2. 秋逢贵人发文书——牛到秋天清闲，秋收冬藏。
3. 强力求之必遭灾。
4. 遇尼（尼姑、珍妮等）主婚事破。
5. 女命：先生外调远方，聚少离多。
6. 肖犬者或姓狄：主丧服，那年戴孝。
7. 肖牛者：顺道受阻，凡事多败，贫且困。唯有读书为上吉，不做决策为上策（人间道）。

#### 山水蒙

![山水蒙](../img/山水蒙.jpg)

先天卦山水蒙：
1. 个性迷蒙，慧镜生尘。
2. 多病多灾。
3. 无子之家，姐妹多，或有子夭折。
4. 二人在江中——二人即夫即父，人入险中，主父母不合、生离死别，父亲有凶。

后天卦山水蒙：
1. 蒙蔽世人，总有财珍宝。
2. 得财遇险——图上台湾宝岛，钱被偷走，得财遇险。
3. 先成后破，晚节不保。
4. 暗度陈仓——人口俱全，人中一横纹。
5. 夫妻二人乘江满财珍宝，得财却有子夭折。

流年卦山水蒙：
1. 十八字——"李"字十八，大吉，财禄亨通。
2. 儿子有夭折现象，发外戚，得义子（螟蛉子）。
3. 财禄散在地上，来路不正，窃取而来。
4. 官司逢之招窃灾。
5. 女命：丈夫遇险，得财先成后破，合伙招凶。

#### 水天需

![水天需](../img/水天需.jpg)

先天卦水天需：天跑到水下面，父先丧，妈妈独养含辛茹苦。攀龙附凤居于尾。五岁之前有凶事。日入草下地中人在中间——爸爸过世后妈妈再嫁，继父有钱把他当亲生子，居在尾巴上。

后天卦水天需：
1. 侍君身策为驶席——驾驶员、公车司机，跟随贵人终其一生（摆着龙尾巴）。
2. 兄弟争财。
3. 老来入空门——门开是空门。

流年卦水天需：
1. 龙在中间——失宠无官，丢官（非己所悦，不得已）。
2. 父凶之虞，爸爸要过世。
3. 草中有玉不见天日——遇事时知此天机。
4. 尾大不掉，任人宰割——不要再相信人家，财物不要给人保管，会被过户。
5. 入空门可解——消极避灾。以前到山里入空门，现在去读书。
6. 婚事有凶——易结难离（摆尾巴不放），待戌年发福禄，或遇肖狗者、名字有狗者、长得像狗的人成事。

#### 天水讼

![天水讼](../img/天水讼.jpg)

先天卦天水讼：
1. 口舌是非总不断，从小在幼稚园就告来告去打小报告。
2. 祸因皆有口无遮拦。
3. 读书事与愿违。动则得咎（扫把星出去就闯祸）。改造方法：坐好不要动，什么话都不要讲。
4. 王虎潜藏，发在他乡——一条路，过去给别人养，不要待在身边。

后天卦天水讼：
1. 官运不通，当官口舌缠身。
2. 幸得财都是险中求（六合彩）。
3. 王姓或肖虎者主贵——王虎唬人为贵，从之吉。

流年卦天水讼（与后天相反）：
1. 你告的人都姓王。
2. 口舌官司，二次官司难免。
3. 肖虎贵人，王为凶人。
4. 随顺风而动则除险平安。刘姓、柳姓者也有"某"在其中，为贵人。
5. 婚姻——婚不成，实无名。
