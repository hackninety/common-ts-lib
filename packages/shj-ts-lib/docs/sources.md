# 数据来源（sources）

## 经文底本

- **来源**：ctext.org（中國哲學書電子化計劃）章节级 `gettext` API，
  `ctp:shan-hai-jing/nan-shan-jing` 等十八卷（见 `docs/corpus/_meta/sources.json` 抓取记录）。
- **性质**：先秦典籍原文，公有领域；ctext 录文大体依郝懿行《山海经笺疏》系统的通行整理本。
- **已知底本特征**（录文如此，本库不改一字）：
  - 个别段落**首字脱落**：如《海外西经》「（三）身国在夏后启北」、《海外南经》「（三）首国在其东」、
    《海外北经》「（一）目国在其东」、《南山经》「（又）东三百里祗山」。实体引文均避开段首取词。
  - 个别用字从底本：形天（刑天）、溪边（谿边）、蠪姪（蠪蛭）、无𦜹（无启）、祗山（柢山）、其名如狰（其名曰狰）。
- **繁→简**：opencc-js（t → cn）转换生成，未做人工润饰；检索折叠表由语料实际用字导出。

## 实体百科 / 山川地望

- 实体条目（名称/拼音/别名/类别/标签/白话简介/流变按语）为本库编写，出处引文由
  `scripts/gen-data.mjs` 在底本内逐字校验锚定（`quoteTrad` 必为底本连续子串）。
- 地望今地与依据字段汇总自通行注疏与常见考据（郭璞注、郝懿行笺疏、毕沅《山海经新校正》、
  《水经注》、谭其骧《〈五藏山经〉的地域范围》及地方志常说等），**置信度三级**标注：
  `identified`（较可考）/ `disputed`（诸说取其一）/ `legendary`（神话示意位，按经文方位排布）。
  坐标仅供可视化，不构成学术结论（`DISCLAIMER` 全文见根入口）。
