# 考刻与推演流程

铁板神数区别于八字学的核心在「**考刻**」：把出生时辰（2 小时）细分为八刻（每刻 15 分钟），
通过已知六亲事实反推刻别，定刻后方能取数查条文。以下流程整理自上游实现
（xaminxan/tiebanshenshu 之 main.py 与 Nanphy/TiebanshenshuOS README），
是坊间流传的一种可操作化重构，非清代原典之权威表述。

## 一、八刻细分

一个时辰细分为八刻，各配天干与刻干数：

| 刻别 | 时辰内分钟 | 天干 | 刻干数 |
|------|-----------|------|--------|
| 初刻 | 0–15      | 甲   | 1      |
| 一刻 | 15–30     | 乙   | 2      |
| 二刻 | 30–45     | 丙   | 3      |
| 三刻 | 45–60     | 丁   | 4      |
| 四刻 | 60–75     | 戊   | 5      |
| 五刻 | 75–90     | 己   | 6      |
| 六刻 | 90–105    | 庚   | 7      |
| 正刻 | 105–120   | 辛   | 8      |

## 二、太玄数（八字取数）

先排八字，再按太玄数歌诀将干支转为数字：

> 甲己子午九，乙庚丑未八，丙辛寅申七，丁壬卯酉六，戊癸辰戌五，巳亥单四数。

## 三、基础取数（对应十四考取数表）

1. **先天命数**：由生年月日时数值合算而得（月值查 14-1 月份表，时支值查 14-2 时辰表）。
2. **五音命数**：以先天命数与年干（五合分组）查 14-3 五音表得宫商角徵羽，再查 14-4 五音数表转数值。
3. **日命数 / 时运数**：以日柱纳音与日干查 14-5 日命表，时柱纳音查 14-6 时运表。
4. **考刻定刻**：按「阳男阴女 / 阴男阳女」分组，以相关数值之和查 14-7 考刻表，先判初刻/正刻两大候选。
5. **本命数与卦象**：本命数查 14-8（简）/14-9（详，分刻别）卦象表得十二辟卦等卦名；
   十二辟卦与刻别查 14-10 先天命数表，得**本命基数**及性格、才能前程、财运、兄弟个数等本命条文号。

## 四、铁板核心公式

```
终局条文数 = 本命基数 + 刻干数 × 48
```

刻干数即八刻细分所得（1–8），故同一本命基数按刻别不同错开 48 的倍数——考刻之所以能定条文。

## 五、六亲考刻

以已知六亲事实验证候选刻别：取各刻别推出的六亲条文（父母生肖存殁、兄弟数目、
妻财婚姻、官鬼功名灾病、子孙数目贤孝），与命主实况比对，匹配度最高者定为真刻。

## 六、流年推演

定刻后逐岁取流年条文（1–108 岁）：

1. 以年支组（寅午戌/申子辰/巳酉丑/亥卯未）与性别查 14-11-1 流年起始表得起始数；
2. 以先天命数、流年天干与月份查 14-11-2 得流年「四声」（四/五/六/七）；
3. 以流年地支与后天命数查 14-12 流年顺序表得流年标记（开/石/土/水/火/发/收/闭…）;
4. 以考刻、日命时运奇偶、四声、标记查 14-13 标记表得**流年字母**；
5. 以条文校正数、流年字母、岁数查 14-14 流年条文表得**基数与加数**，
   `流年条文号 = 基数 + 加数（经校正）`，查条文库得当岁断语；断语年龄注记与实岁相验。
