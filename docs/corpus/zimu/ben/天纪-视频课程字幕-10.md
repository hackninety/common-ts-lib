# 天纪-视频课程字幕-10

> 《人纪》讲稿系列之《天机道》《人间道》《地脉道》

## 第十章 续卦与堪舆学罗经

### 卦象续讲

#### 天风姤

![天风姤](../img/天风姤.jpg)

夬卦之后是天风姤。姤是相遇之意——决而后必有遇，决者快也，满溢出来后必有相遇之象出现，故夬卦之后受之以姤。易经在姤卦中专讲相遇之道：君王与贤臣相遇、男女朋友相遇、夫妻之间皆有遇之道。

自然之象：天在上面，风在天的下面吹，风一动万物皆被吹动，代表能够遍处万物——此即天风姤之象。能够把政策推到深山里的人都听从你的话，是天下无权之至，真正的圣贤不但让人听，更让人一心归向。

**人间道**：君臣不遇则政策不行，万物之事若无外物协助则功用不生——如录音机不插电便无功能。一人不能成事，须众仰才能成事。第五爻君子姤之道：君王求贤要与贤人相求，以至高之尊求下黎民百姓，则人才无有不至。今人反其道：君王一天到晚飞出去外求，臣民来求时也不求下，只看君要什么便做什么。同气相求，连战有好的决策要办到底时，旁人便因"功高震主"而阻挠——伴君如伴虎，对百姓有利之事也被猜忌。易经明言：相求一定要求下，绝不外求。展现自己魅力让人家过来求你，才是治本之道。

**占卜**：

1. 官人涉路、取禄状——主得外财、横财。
2. 闻书尚有喜事——喜事飘着红头绳，无枝无杆，摇摇欲坠；根只一线——卜到夫妻凶。
3. 二人执锁——两人绑在一起，互相牵连牵累。问官司一卜天风姤，肯定有事情被拖累。
4. 绿衣人指路——中国几千年文化记载，凡去回阴间回来的人（包括包拯查看生死簿），掌生死簿的人都穿绿衣。绿衣人是掌生死簿之人，今之信差。卜卦可卜到阴间之事。
5. 群党阻挡——四个人做朋党阻拦先生，一人在旁摇手，上边两重山有阻隔之象。

**阳宅天风姤**：父居长女位（爸爸住东南角），成格。对爸爸是天风姤，对妈妈是地风升。

1. 财禄丰盛，有野外之财（如六合彩中奖、股票赚到钱）。
2. 会有官司牵连——住天风姤卦官司很多。
3. 喜事随风飘——外面有妻妾，姤有交合之象，男人犯桃花，夫妻失和。此位置对夫妻不好。
4. 时间上六年之内平平，前三年旺，第三年与第七年凶（血光灾）。住进算起第三年、第七年最凶。

举例：主卧房在东南角，姤卦出现。八字一看第三年大小二相逢——问住多久，刚搬进去三年，姤卦应在第三年。若前面已住四年，到第七年流年逢杀星无吉星来会，再加上住天风姤，正好第七年发生血光之灾。

#### 泽地萃

![泽地萃](../img/泽地萃.jpg)

天风姤之后是泽地萃。姤是相遇，万物相遇后必有聚——聚即现在聚集之意。自然之象：平地上沼泽水聚在一起，即萃象。外卦泽为悦，内卦地为顺——外面喜悦高兴，内部柔顺，一定很多朋友来找你，但需选择：选君子是真正萃道，选小人则不是。

**人间道**：圣人观萃象知道民心之聚莫过乎宗庙——立宗庙立得对，人心很快就能收起来。王立宗教一定要讲孝，以孝道宗庙为立。现在人过年跑去做基督教礼拜，却不敬孝上香祭祖——百善孝为先，历代宗王都非常敬视祖先，知道孝顺。

妈祖生日时不管民主党国民党全部跑到妈祖庙去——圣人厉不厉害？立宗庙收人心，但重要如何立不讲。台湾花钱去外交讨好非洲黑人总统是没用的——他不念易经，糊涂愚蠢。

**占卜**：

1. 贵人磨玉——一人磨玉，代表进修，专心一致的心，坚信到底不能间断，小心不让它破碎。
2. 僧指路——僧手指指引。生人代表局外人；僧同音曾姓；光头人也是僧，看头发——牧师光头也是僧。
3. 小儿在山路——当官或做生意的人有退隐山林之象，以退为进。
4. 一人救火——救灾祸、求救，代表救火队，也代表行医之人济事救人。
5. 鱼在火上——鱼得救，本来要被烧煮，火一浇下去鱼得救了。
6. 凤衔书——孔雀金凤画上，代表喜讯、好消息要来。讲凤不讲乌鸦——喜讯要来。

**阳宅泽地萃**：三女居母位，成格。

1. 不想成婚，未婚有子。
2. 终日进修业。
3. 代母职，居家内——出去工作不喜欢，待在家里面，生小孩不需要结婚。

例外：开餐厅卜到泽地萃大吉。

### 堪舆学续论（罗经）

#### 八煞黄泉

八煞黄泉是立项用的，包括阳宅、阴宅都用此立项。歌诀：**坎龙坤兔震山猴，巽鸡乾马兑蛇头，艮虎离猪为曜煞，墓宅逢之一且休。**

八煞黄泉是最凶的煞，绝对不可以立项。如：坎龙入首不能立辰向、坤龙入首不能立卯向、震龙入首不能立申向。

罗经第三圈即黄泉煞。测量定向时遇到坤，便有黄泉煞。所谓"山"即坐山——山龙来向。来龙是丁龙就叫丁山，不立坤向。丁山是睽向，山的对立面是睽，坐山即来龙。立项不一定要正对来龙——地势不一定凑巧，常转动。八煞黄泉专门讲立项跟来龙的关系。

#### 八路黄泉

八路黄泉专门讲来水或去水。歌诀：**丁庚坤上是黄泉，辛壬水路怕当前，癸向忧见甲和艮，乙水须防巽丙先。**

龙穴来水或去水时，八个地方不可以来水，犯之主孤寡（孤儿寡母）。如立庚向，坤方不可有水进来或出去；立丁向同样，坤方不可有水。八路黄泉完全看水的来去。最好的位置是看不见水来、看不见水去。水若直来直去（直进直出）力量很大但非常凶。水要来无影去无踪、安安静静、还要聚。

#### 九星四环局

九星可当坐向、可当朝山、案山。九颗星跟24个坐山来龙测定时，最重要是用在庚脉——来龙必须庚。面对贪狼（近为案山，远为朝山），或龙虎臂上有贪狼局，或明堂内、水上有贪狼局——贪狼不一定是大山，有时岩石刚好排列成那个形状。

庚脉属木，属性相同叫比肩。五行相生：木生火、火生土、土生金、金生水。相克：木克土、土克水、水克火、火克金、金克木。比肩发科甲，读者读书很好、考试顺利。

#### 三吉六秀

天星六秀：亥、震、庚为三吉方；艮、丙、兑、丁、巽、辛为六秀方。

阳宅或阴宅坐上后，三吉方或六秀方有来龙、马路、朝山、峦头、好砂，统统并入三吉六秀。若有六秀三吉是大吉之地。角度差一点移到位子上叫拨砂。

#### 龙穴土色

- 砂为贪狼墓，穴土色必青
- 巨门则黄
- 红光光润为吉

红土地气太热太旺，台湾火山多，地气很热。土色区分真龙假龙：来龙很大包住过峡时两边高山挤得窄，峡土颜色必须相同于穴内土色——这是同一条地脉。峡土青色，穴挖出来必须是青色；若峡土青色穴挖出红色，则找错地脉了。最高者在峡的地方测来龙，对着龙向立项。

红土气太盛用泻葬法；气不足（石多土少）用补土法。

#### 骑龙葬

龙穴已被占时，能在周围吃到龙脉风水也是高手。龙脉灵线很长一条下来，结穴被抢走，没地方葬就在脉上面葬——骑龙葬。骑龙葬若位置高，远山紫薇星比眼睛低、比心脏高即可定他——下面出臣民，上天出天子。

#### 土色与牛眠地

穴中挖出的土若像玉一样晶莹剔透、切下整整齐齐不散，为吉；若像枯萎白色盐巴色无光亮，为凶。满山皆同色为平常穴。穴中有龟有鱼是天地精气，奇特佳穴；有蛇蚁鼠虫是凶穴。

动物比人厉害——乌龟晚上丢到厕所早上在西北角，丢到客厅晚上还是西北角，动物会找安全的地方。牛眠穴：牛做完主人工作后放草，它一定找最舒服的地方躺，第一次躺哪边第二次还是同一边，恢复疲劳很快。找到龙穴的地叫牛眠地，看牛。家里有动物来聚是吉，但蛇鼠一窝不算。家里蟑螂老鼠打包袱往外走就是有火灾了。

#### 兄弟阋墙与分房宫位

长房二房中间立方向若插两根棍子，罗经上一看便知——两兄弟会阅墙争财产。

山砂秀丽要有情（山突出无树叶或几根干草是无情；水直来直去是无情）。来龙泻气无气时，分房论法：

- 一子：满盘都印在一个人
- 二子：左青龙代表长房，右白虎代表次房
- 三子：左青龙长房，明堂正中中房，右白虎三房
- 四子：青龙前锋上
- 五子：正案上面
- 六子：白虎案上面

长房来龙大龙比虎大龙高，看前面直角伸出多少——伸出越多长房发越强，一条支脉管十年，十条支脉管一百年约三代。

#### 穿山72龙

24个坐山一圈，一个坐山管三条龙，3×24=72龙。穿山72龙测来龙，在峡中磐正，无峡则在入手主星后面测。罗经第六圈即穿山72龙，又叫72分经。12地支与10天干最小公倍数60加8班四围加12变72，所以有12个地方空（凶位）。

一山统三龙：圈圈代表大吉，三角形代表次吉，无标注统统是凶。罗经上红底金圈统统是吉，金底黑圈或打XX的统统是凶。

阴龙立阴向，阳龙立阳向——地盘针分阴阳龙。阴龙中又分三个，阳龙中一个龙又分三个——看吉凶，吉的设立，不吉的离开。

#### 天罡二十八宿

罗经倒数第二环为天罡二十八宿：东方七宿、南方七宿、西方七宿、北方七宿。二十八宿属恒星。罗经放地上南北时针对准后，天时对好，天上经纬度就划出来了。

如东方卯下来最外倒数第二行指16度少，左边行9度太——"太"是接近100分（接近一度），"少"是接近50分。一度分100分。罗经刻到360度，实际可再刻很细。

#### 七政与天机

日月木火土金水共七政。日月五行会动，叫列星。看日月五星在天上经过二十八宿的动向，可知整个地球的地纪与运转周期。

天机一垂象，静止四天可测一年动向，甚至可测冰灾、奸臣昏君、大水改道等。比现代气象台快得多。科学家研究星球组成知道有隐秘，他们所知有限——月球引力影响潮汐他们承认，金木水火土老祖宗早知道。

#### 天人地三盘

罗经三圈24个坐山：第一圈地（地盘针，格龙用）、第二圈人（人盘针，中针比地盘后半位，消煞用）、第三圈天（天盘针，比地盘前半格，缝针，纳水用——测水来龙）。

先有天，有地，然后有人。人比地再慢半格。天比地多半格，地比天慢半格。

#### 二十八宿配24山

坐前山为奎木狼，前配奎木狼——24坐山与天上28天罡星配在一起。奎木狼属木，见到需与坤属木，木与睽木同项，属性相同叫比肩，比肩人才发科场，发科甲读书顺利。

属性看相生相克：木生火火生土土生金金生水相生为吉，相克为凶。

#### 透地60龙

透地龙是棺材放到地下时那个位——摆下去左转右转叫透地龙。穿山72龙测来龙，透地60龙审龙气入口。

透地60龙立在葬下去时的珠宝线上。罗盘60甲子中：标"三七""七三"共24个是"差错空亡"；标"五"字共12个为"火坑"；标"正"字共24个合二十四山正气脉，为珠宝线。火坑与差错空亡都不好，埋下去时一定要在珠宝线上面。

入穴葬好后，外面墓碑与里面棺木要九十度摆好——方便后面风水师来看。正派就不怕别人看。

#### 风水喝名

喝名字看外形，以象来定。山脉下来一段一段后面龙骨两个凹下去像大象就叫大象，像舞狮的狮子对面是绣球就叫狮子绣球。牛穴可叫犀牛——朝西取同音。山头短短草无树木形如牛毛很多叫犀牛穴——当场形状决定。

### 卦象续讲（续）

#### 地风升

![地风升](../img/地风升.jpg)

泽地萃聚之后受之于升。萃是聚的象，越聚越大往上升。地下面有木（风在五行属木），木往地上生长，所以叫地风升。

此卦专论升之道。君子升之道：顺时而进——得到时机，下位往上升上位反而顺，即升之道。

**人间道**：君子平常顺时修德，静得修业，随时在修德，不以升为目的；未升时就累积，实质时以才能胜任恰得其分。文王最懂升之道：当诸侯时，对下举升贤能之人，对上欲使天子有道而非篡位，故能得天下创立基业。

第五爻讲大臣之人（今之宰相、院长、部长）——不得无事而升。大臣当上升君道功德，下升天下之贤，使人适其位。现在国家无事而升，无功劳也升——升者必有私欲野心，不当其位。晏婴三朝宰相讲：看人发达时看他举荐何人——举荐不当便知其人如何。

**占卜**：

1. 云中雨点下——恩泽，受恩泽之象；昏暗时将过。
2. 木匠下墨解木——墨绳打线锯开木头，有法则、依归、尺度、依据，以武力去灾。
3. 一人磨镜——可得镜子，始成之象，刚开始成就。
4. 架子扶大木——不小之财。问生意可成赚钱。
5. 明镜高悬——卜诉讼遇公正廉明法官。
6. 做生意卜到——有竞争（两人字写得开靠拢为争）。
7. 男子左下角蓝子——蓝同音难，男人难也，百废待兴之象，另一朝代开始。

**阳宅地风升**：母居长女位（夫妻都住东南角，先生是天风姤，太太是地风升）。

1. 太太任官职，官职大利。
2. 做事业，财禄很多。
3. 承继祖业并发扬光大，改朝换代。
4. 夫妻住东南角，先生天风姤太太地风升——夫妻有竞争不和。
5. 婚事进入第七年凶。从太阳卯时出来到午时（上午6点到中午12点），从东到南刚好三格宫（正宫、震宫、离宫）6个小时6住6引。前段旺，第六年后到第七年完蛋。七年之痒从易经来。住进去就开始算第七年。

#### 泽水困

![泽水困](../img/泽水困.png)

天下万物升升不已，升到一定高度就不升，升之尽必招困。天道自下而上，由下而上用力晋升不久一定招困。困卦讲什么样的状况会让人困，困时怎么办。

**人间道**：君子处困乐天安命——本不是那个咖，坐不适合的位置理所当然要困。想去就是困之始。处困时一定要乐天安命，随时善处。算命给先生说"未来很好，今年困是正常的"，阴德就积起来了——哪有那么多好事。

困之义：外悦内险——外面高兴笑，里面担心很多事情，就是困。看人很开心但内心在想事就是困。

**占卜**：

1. 药炉放在地上——有人来救，代表有人来救。
2. 要待时缓进——等待时机缓慢进步。以守，还要教以悦之道，万事喜悦。
3. 贵人井水求五彩——求财无财，但有贵人在接水相救，支援钱财。
4. 池中有青草——目前仍有生气，事业还是可以做。困时不要紧张，一个字"悦"。

**阳宅泽水困**：三女居二子位。老三每天脸上无泽即泽水困。

1. 体弱多病，性刚独行，不听父母话。
2. 婚事不成，一辈子无婚姻。
3. 财禄不守，给多少花多少，守不住祖业。

#### 水风井

![水风井](../img/水风井.jpg)

困卦之后是水风井。人受困以后必下，往下走，落若井。风是木，水跑到水下面，木入水中，有汲水于井之象。

**人间道**：

1. 城邑改，井不改——换到别的地方井没挖没水了，井不能动。告诉你要坚信正道，不能坚信歪道——不正之道上坚信是执迷不悟。
2. 取之不竭，存之不盈——井水倒出来第二天又满。井无私又无德。
3. 人至皆泽其用——不管什么人走到旁边都可以用得到它，这是井的德。

**旧井之戒**：井泥即旧井之戒。君子随时在进德，像井一样每天积累，日新月异，不会因外面发生什么事而停止，每天都在进步。现在很多大学教授拿出十几年前的讲义教经济学，不再进修——"我是博士了，不需要进修"——这就是旧井。真正的井之道是取之不竭存之不盈，每天在存、在吸收，不会自满，每天还在进步。每天找你一两个月看不到就很紧张因为你会进步很多。不读书鼻子越来越歪，读书的人鼻子越来越正。

**占卜**：

1. 金甲神持福在床边——贵人在空中，祥瑞之兆，来救你。
2. 女子抱盒——好也；盒子先成后破。
3. 钱宝有光喜——卜财不失，不露不会露出来。
4. 地下烧纸钱——家中不久有丧。
5. 人落在井中——病重，或官司呈现、冤狱、遭陷害。
6. 官人用绳引出来——贵人救你，有人帮你伸冤。
7. 旁人作对——竹字头策略，人字旁有人，旁人在作对。

**阳宅水风井**：二子居长女位，成格。

1. 未婚二子婚事妻长——太太年龄大，且是二婚妻。
2. 带丧服——突然住东南角家中戴孝。看太阳落陷还是太阴落陷，看日角暗还是月角暗；看左眉高还是右眉高。
3. 颈生病——淋巴癌、大脖子等脖子部位有病。
4. 从商吉——有钱在地上，做生意很急，从祖业。不从商从官则遭诬陷。

#### 泽火革

![泽火革](../img/泽火革.png)

井卦之后是泽火革。井里的东西若丢一块下去，井就坏掉烂掉——井没有外通，一坏就有革的象出现。一粒老鼠屎带坏一锅粥。台湾好像百姓都好人都聪明，一粒老鼠屎出现就危险了，这时就要去革。"革命"一词不是孙中山发明的，易经早就讲革命了。

须革的原因：要去改革，不是要革命。火在上面泽在下面（火在下烧水在上），两不相通——若火在上水在下就是火泽睽（相悖）。火在下面烧水会蒸发掉——物象改变，革有改变、改革、变迁之意。

**人间道**：二女同居其志各异——两个女孩子同居想法完全背道，各不相格，水火叫格。革之道要去故。始革时人心未信，到了巳日后人开始信（不是看皇历巳日，而是形容一段时间）。

革卦条件：

1. 必有其时——当有天灾时、当人民都反对君王时。
2. 必有其位。
3. 必有其才——真有才能。

三条件具备后要谨慎小心审虑而后动。没有位置没关系，赶快去静修其才。

**占卜**：

1. 一人把式全、一人把式不全——一人肺腑之言（实话），一人半真言（一半实话一半虚话）。
2. 兔子在地上——跃进之象。
3. 虎——权威之象、大人之象、官人之象。兔子跟在老虎后面走。
4. 文官推车带印——主得到分封封侯，上任后必定力求改革（前面留烂摊子给你）。武官推车代表诉讼、准备打官司。
5. 虎兔上山——贤良之人退居山林，兔子跟着老虎走。
6. 山头上四个黑点——君王不明，小人当道（四黑点在土上面）。

**阳宅泽火革**：三女居二女位，成格。

1. 性刚而明——三女儿体弱多病，住革卦改变后性刚脑筋清楚。缺点是困扰于感情——有人诚心诚意爱她，有人虚情假意，半真半假，很困扰不晓得选择哪一个。
2. 婚事提前两年——命里28岁红鸾星动，住这里提前到26岁；结婚时比姐早，妹妹先结婚。
3. 当公务员或当官——官运亨通。
4. 从商不利。
5. 利科甲——最利科甲的是风泽中孚（状元卦），革卦也对科甲很好。
